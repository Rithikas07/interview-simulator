JAVA AI INTERVIEW SIMULATOR

A console-based, offline-capable core-Java mock-interview and placement-readiness tool

ABSTRACT
Practises core-Java placement interviews through a console app that loads a 23-question bank from JSON, lets the candidate pick a question-setting strategy, and scores each typed answer with a keyword evaluator that falls back automatically if an AI backend is unavailable. A 34-test JUnit suite passes at 100%, and a real demo session scored 73% overall with a topic-wise breakdown.
INTRODUCTION
Placement interviews test OOP, Collections, Strings, Exceptions, JVM and Multithreading, but students rarely get interactive, offline practice with instant feedback. This project builds that practice tool in Java itself, so building it reinforces the very concepts it tests, and keeps it free of any paid or network dependency.
OBJECTIVES
  • Design a 6-topic, JSON-backed question bank
  • Apply OOP + design patterns (Strategy, Factory, Decorator)
  • Build a pluggable, fail-safe answer evaluator chain
  • Offer random / balanced / topic-focused question setting
  • Verify logic with an automated JUnit 5 test suite
